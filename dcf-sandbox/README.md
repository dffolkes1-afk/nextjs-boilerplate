# DCF Sandbox: Android app

Open this link in **Chrome** on your Android phone to download, then tap **Open** to install:

https://github.com/dffolkes1-afk/nextjs-boilerplate/raw/dcf-sandbox-download/dcf-sandbox/DCF-Sandbox.apk

App file only (v3.3). No source code or personal data.


## Newest version (never stale)
Each release has its own file: open `version.json` to see the newest `DCF-Sandbox-<number>.apk`. From v2.9 on, DCF checks this itself and offers the update.
